Academic Subject Integration

How This Project Works

Designed and implemented to demonstrate practical synergy between core computer science disciplines: Advanced Data Structures (ADSA), Discrete Mathematics (DMGT), Object-Oriented Programming (OOP), and Python Machine Learning.

ADSA Integration

Self-Balancing AVL Tree

Implements an authentic Adelson-Velsky and Landis (AVL) binary search tree maintaining balance condition |height(L) - height(R)| ≤ 1. Features Left-Left (LL), Right-Right (RR), Left-Right (LR), and Right-Left (RL) rotations. Prefix tree lookup achieves true O(log N + K) autocomplete lookup in < 0.2 ms across 5,050 products.

DMGT Integration

Set Operations for Filtering

Product multi-attribute filtering is modeled mathematically using Discrete Mathematics and Graph Theory (DMGT) set algebra. Products form Universe U. Category sets Scat, brand sets Sbrand, price interval sets, and stock sets are combined using set union (∪) and intersection (∩):

Sresult = (∪ Scat) ∩ (∪ Sbrand) ∩ Sprice ∩ Srating ∩ Sstock

OOP Integration

Object-Oriented Design

Built using strict OOP principles in both backend (Python) and frontend (JavaScript). Encapsulates domain logic into decoupled classes: Product, CartItem, Cart, Customer, OrderItem, Order, SearchEngine, and ProductRecommender with full data integrity.

Python NLP Integration

TF-IDF & Cosine Similarity

Product recommendations are calculated dynamically at runtime using Natural Language Processing (NLP). Product descriptions and specifications are converted into L2-normalized TF-IDF vector space embeddings. Cosine similarity calculates angular proximity:

cos(θ) = (A · B) / (||A|| · ||B||)

Top 5 similar products are returned dynamically without hardcoding.
